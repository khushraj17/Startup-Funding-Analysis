#  Startup Funding Analysis Dashboard


This project is an **interactive data analysis dashboard** built using **Streamlit** that provides insights into startup funding trends in India.

Users can explore funding patterns, investor behavior, and startup performance using dynamic visualizations and filters.

---

##  Key Features

###  Overall Analysis
- Total funding, average funding, and max funding
- Top funded startup
- Month-over-Month (MoM) trends
- Number of startups funded over time

###  Startup Analysis
- Analyze individual startup data *(extendable feature)*

###  Investor Analysis
- Recent investments
- Biggest investments
- Sector-wise investment distribution
- City-wise investment distribution
- Funding trends over time
